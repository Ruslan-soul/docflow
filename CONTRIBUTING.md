# Contributing

Bug reports and focused improvements are welcome. Before opening a pull
request, describe the user problem and keep changes small enough to review.

## Development setup

Use Python 3.12 or 3.13, create a virtual environment, and install
`requirements-dev.txt`. Run the test suite, syntax check, and `pip check` as
described in the README. Add or update tests for behavior changes. Do not include
real customer files, secrets, local logs, or generated output in a change.

The project currently has no code reuse license. Opening a contribution does
not grant the public broad rights to reuse the project; ask the maintainer
before contributing code that depends on a particular license.
